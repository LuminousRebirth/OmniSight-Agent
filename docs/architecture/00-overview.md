# 00 · 全局架构与设计总览

> 所属：docs/architecture/（整体核心构建框架）
> 配套：构建过程实时记录见 `docs/build/`；权威规范以 `PROJECT_SKELETON.md` 为准，本文档不臆造 schema/API。

## 1. 项目定位

**YOLO + 多模态 Agent 多功能图片/视频识别检测工作台**：上传任意图片/视频/接实时摄像头 → 系统自动路由到已审批 YOLO 模型检测 → VLM 语义分析 → RAG 知识依据 → Agent 编排全链路；**不绑定数据集**——未知类别零样本兜底，人工确认后自动转正为新任务。

四要素：**YOLO=视觉通路**（毫秒级坐标）｜**VLM=分析大脑**（语义结论）｜**RAG=经验记忆**（依据与先例）｜**Agent=调度中枢**（编排全链路）。

## 2. 分层架构

```
┌──────────────────────────────────────────────────────────┐
│ 前端层  React 18 + Vite + TS（6 页面工作台）                │
│  识别工作台(/detect) │ 对话分析(/chat) │ 模型库(/models)    │
│  数据集(/datasets) │ 训练中心(/training) │ Agent画布(/agent-builder)│
├──────────────────────────────────────────────────────────┤
│ API 层  FastAPI REST + WebSocket（训练指标/检测帧/告警三路）│
├──────────────────────────────────────────────────────────┤
│ Agent 编排层  Agent 调度 │ 四级路由决策 │ 长记忆 │ MCP 网关 │
├──────────────────────────────────────────────────────────┤
│ 能力层 检测(插件化+零样本) │ VLM(双通道) │ RAG │ 训练 │ 告警 │
├──────────────────────────────────────────────────────────┤
│ 数据层  SQLite(起步) │ 本地文件(data/) │ numpy向量(起步,可换Milvus)│
└──────────────────────────────────────────────────────────┘
```

## 3. 技术栈（版本以安装时最新稳定版为准）

| 层 | 选型 | 用途 |
|----|------|------|
| 前端 | React 18 + Vite + TypeScript | SPA；ECharts 指标曲线；ReactFlow Agent 画布；Ant Design 管理组件 |
| 后端 | FastAPI + Uvicorn | REST + WebSocket + OpenAPI |
| 检测 | Ultralytics YOLO + PyTorch | 训练/推理/导出一体 |
| 视频 | OpenCV VideoCapture + ffmpeg | USB/OBS 虚拟摄像头/RTSP 拉流 |
| 元数据 | SQLite（连接层封装，可换 PostgreSQL） | 模型/数据集/任务/告警/记忆 |
| 对象存储 | 本地文件系统 `data/`（接口对齐 MinIO/S3） | 图像/权重/标注 |
| 向量 | numpy 内存实现（向量化工厂封装，可换 Milvus/ES） | 能力/记忆/知识向量 |
| 路由粗筛 | CLIP（open_clip） | 图片语义编码/相似度 |
| 零样本 | YOLO-World（提示词检测，可后装） | 未训练类别兜底 |
| VLM | 通义千问VL / OpenAI 兼容 / 本地 Qwen2.5-VL | Provider 抽象双通道 |
| 文本检索 | bge-m3 编码 + bge-reranker 重排（Phase 2 可后装） | RAG 中文检索 |

## 4. 设计原则（贯穿所有模块）

1. **插件化**：检测器=插件、模型=注册表条目、VLM=Provider，新增零侵入
2. **异步化**：一切超秒级操作返回 `task_id`
3. **权限门禁**：写操作必须审批/鉴权；MCP 工具最小权限挂载
4. **留痕可审计**：审批/路由/工具调用/记忆沉淀全部落日志
5. **知识质量优先**：只有人工确认结果进 RAG 案例库
6. **多功能定位**：不绑定数据集；未知输入零样本兜底不抛锚

## 5. 双通道架构基调（已与用户确认）

**本地保底、云端增强、Provider 隔离、逐级降级**——任何单点（无 GPU/云端断连/无权重）不抛锚：

| 能力 | 本地通道 | 云端通道 | 切换策略 |
|------|---------|---------|---------|
| 训练 | PyTorch 本地（GPU/CPU 自适应） | 预留接口位 | 训练执行器抽象 |
| VLM | 本地 Qwen2.5-VL（可选装） | 通义千问VL / OpenAI 兼容 | Provider 配置切换 + 自动降级 |
| 零样本 | YOLO-World（本地权重） | — | 纯本地 |
| 向量 | numpy 起步 | Milvus 接口对齐 | 向量化工厂封装 |
| 路由 | CLIP 粗筛本地 | LLM 决策器走云端 VLM | 四级路由逐级降级 |
