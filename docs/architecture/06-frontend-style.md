# 06 · 前端视觉规范（简约白蓝）

> 依据 frontend-design skill 为"识别检测工作台"定制的视觉 Token 系统。
> brief：**简约白蓝**——精致执行、克制装饰、单一记忆点。
> 应用范围：Phase 1 前端骨架（T7.12）起所有页面。

## 1. 设计基调

白底蓝饰的工业级工具感：亮色应用外围 + 深色检测画布对比；装饰最少化，信息密度优先；检测数据（坐标/置信度/FPS）用等宽字体呈现"仪表盘"气质。

## 2. 色彩 Token

| Token | 色值 | 用途 |
|-------|------|------|
| `bg` | `#F8FAFC` | 页面底色（极浅灰蓝） |
| `surface` | `#FFFFFF` | 卡片/面板/顶栏 |
| `primary` | `#2563EB` | 主蓝（按钮/链接/选中/检测框描边） |
| `primary-soft` | `#EFF6FF` | 浅蓝底（hover/高亮背景/徽章底） |
| `text` | `#0F172A` | 主文字（深蓝黑） |
| `text-secondary` | `#64748B` | 次要文字/说明 |
| `border` | `#E2E8F0` | 细分隔线/描边 |
| 语义 | `#16A34A` / `#D97706` / `#DC2626` | 置信度高/中/低，告警 tip/warning/emergency（克制使用） |

## 3. 字体层级

| 角色 | 字体 | 用法 |
|------|------|------|
| 显示/标题 | 系统无衬线栈，weight 600，字距 -0.01em | 页面标题/卡片标题 |
| 正文 | `-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif` | 常规内容 |
| 数据/标签 | `"JetBrains Mono", Consolas, monospace` | bbox 坐标、置信度、FPS、分辨率、task_id 等监控数据 |

## 4. 布局概念

```
┌──────────────────────────────────────────────┐
│ 顶栏：面包屑 / 模型状态徽章 / 用户（白底+细分割线）│
├──────────┬──────────────────────┬────────────┤
│ 左栏(白)  │  检测画布（深色 #0F172A）│ 右栏(白)   │
│ 采集源/   │  蓝色检测框+置信度徽章    │ 告警/结果  │
│ 模型控制  │  蓝色准星网格（签名）     │ 滚动列表   │
└──────────┴──────────────────────┴────────────┘
```

- 识别工作台三栏布局；数据集/训练/模型库页用标准列表+卡片布局
- 深色画布 `#0F172A` + 检测框 `primary` 描边 + 置信度胶囊徽章

## 5. 签名元素（记忆点）

1. **检测画布蓝色准星网格**：画布叠加淡蓝网格线 + 中心准星，体现"检测/瞄准"主题
2. **检测框蓝光描边 + 置信度徽章**：命中目标蓝色描边 + 右上角渐变蓝胶囊（置信度 %）
3. **顶部蓝色渐变状态条**：实时检测时模型名 / FPS / 分辨率 / 帧数实时滚动显示

## 6. Ant Design 定制

```ts
// theme token（frontend/src/theme.ts）
{ colorPrimary: "#2563EB", borderRadius: 8, controlHeight: 36, fontSize: 14 }
```

## 7. 文案规范（frontend-design skill）

- 动作按钮说结果："保存更改" 而非 "提交"；全流程同一动词
- 错误/空状态是引导而非道歉：空数据集显示"上传图片或视频开始构建数据集"
- 界面用词从用户视角命名，不暴露系统实现（"通知" 而非 "webhook 配置"）
